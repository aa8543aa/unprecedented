## 논의 내용

- 오너 지시: 작업 단위마다 이슈 → 커밋 → PR → 머지를 매번 진행하고, 작업 순서를 기록으로 남긴다.
- 화면이 의존하는 순서대로 구현했다: 계산 모듈(#22) → 설정 화면(#23) → 주행 화면 UI(#24) → GPS 속력(#25) → 카메라 백미러(#18).
- 주행 화면은 배경과 조작부를 바깥에서 받게 만들어, GPS와 카메라를 나중 PR에서 붙여도 화면 코드를 다시 고치지 않게 했다.
- 테스트 도구가 없어 #22에서 vitest를 추가했다.
- 브라우저 미리보기에서 375×667 화면일 때 부상도 막대가 하단 조작부와 겹치는 문제를 찾아 #18에서 막대 길이를 화면 높이에 맞추도록 고쳤다.
- 미리보기 환경에는 위치 권한과 카메라가 없어, GPS·카메라가 없을 때의 대체 동작(슬라이더, 어두운 배경)만 확인했다. 실제 주행 속력과 카메라 영상은 HTTPS 실기기에서 확인해야 한다(#30 정적 배포 이후).
- 진행 중 PR #21의 브랜치를 머지 확인 전에 지워 PR이 닫혔다가, 브랜치를 다시 올리고 PR을 다시 열어 머지했다. 이후로는 머지 상태를 확인한 뒤에만 브랜치를 지운다.
