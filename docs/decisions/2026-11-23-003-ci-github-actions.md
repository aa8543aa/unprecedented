## 배경

로컬 pre-commit 훅은 `--no-verify`로 건너뛸 수 있고, 협업자의 환경이 다를 수 있다. 서버에서 한 번 더 검증해야 한다.

## 결정

- PR과 main push 때 `lint → format:check → build`를 실행한다.
- Node 버전은 `.nvmrc`(24)로 로컬과 CI를 맞춘다.
- 같은 브랜치에서 새 실행이 시작되면 이전 실행은 취소한다.

## 이유

- GitHub 저장소와 바로 연동되고, public 저장소는 무료다.
- build에 `tsc -b`가 들어 있어 타입체크도 함께 된다.

## 영향

- 테스트 도구를 도입하면 CI에 test 단계를 추가한다.
- main 브랜치 보호(CI 통과 필수)를 켜면 규칙 1을 강제할 수 있다. 적용하면 별도 문서로 남긴다.
