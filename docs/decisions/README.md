# 의사결정 기록 (Decision Log)

이 프로젝트의 **모든 의사결정**을 "왜 이렇게 했는지" 중심으로 남깁니다.
규칙은 [2026-11-23-008-decision-log.md](2026-11-23-008-decision-log.md)를, 양식은 [_TEMPLATE.md](_TEMPLATE.md)를 참고하세요.

## 작성 규칙 요약

- **필수:** 모든 결정은 [회의록](../meetings/README.md)과 함께 남기고, 문서 맨 위에 한 줄 이유를 적음
- 결정 1개 = 파일 1개, 파일명 `YYYY-MM-DD-<이슈번호 3자리>-<슬러그>.md`
- 결정이 나온 PR에 함께 포함
- 결정을 뒤집을 때는 기존 문서를 `대체됨`으로 표시하고 새 문서 작성
- 아래 목록을 함께 갱신
