# 화면 디자인: 백미러 배경 위에 좌우 부상도

> **한 줄 이유:** 주행 중 폰 화면은 뒤를 보는 백미러로 쓰고, 그 시야를 가리지 않도록 수치는 위쪽과 양 끝에만 띄운다.

## 배경

아이디어가 [자전거 충돌 위험 계산기](2026-11-23-004-idea-bike-collision-risk.md)로 정해졌고, 프로젝트 구조와 기능을 정하기 전에 화면을 먼저 정하기로 했다.

## 검토한 선택지

1. **좌우 카드에 원형 % 그래프**: 숫자가 눈에 잘 띈다 / 카드가 넓어져 가운데 시야를 가린다
2. **화면 양 끝 세로 막대**: 가운데 백미러 시야가 넓게 남는다 / 막대가 좁아 숫자를 따로 크게 써야 한다
3. **하단 가로 막대 두 줄**: 읽기 쉽다 / 뒤쪽 시야의 아래쪽(가까운 차량)을 가린다

## 결정

선택지 2. 디자인 시안: [Claude 디자인 캔버스](https://claude.ai/artifact/1fyZVeQfbTfuTWytuukH3y) (오너 계정에서만 열림)

**주행 화면 (세로 390×844 기준)**

- 배경: 후방 카메라 영상 전체 화면. 권한이 없으면 어두운 단색.
- 상단 중앙: 내 속력(큰 숫자 + km/h)과 GPS 상태.
- 왼쪽 끝: 나. 라벨, 자전거·몸무게·헬멧 요약, 세로 막대, 부상도 %, "전치 약 N주", 부상 단계.
- 오른쪽 끝: 충돌 대상. 대상 이름 버튼(누르면 보행자 → 자전거 → 오토바이 → 승용차 → 트럭 순환), 대상 무게·속도, 세로 막대, 부상도 %, 전치, 단계.
- 하단: "이 속도로 정면 충돌하면 (상대 N km/h 가정)" 전제, "참고용 추정 · 의료 판단 아님 · 100% = 사망", 설정 버튼.
- 좌우 사이에 "vs"는 넣지 않는다.
- 모든 수치 영역은 반투명 어두운 판(블러) 위에 흰 글씨.

**부상도 단계와 색**

| 부상도 | 단계           | 전치 표시        | 색   |
| ------ | -------------- | ---------------- | ---- |
| 0~2%   | 부상 거의 없음 | 전치 1주 이하    | 파랑 |
| 3~14%  | 경상           | 전치 2~3주       | 파랑 |
| 15~34% | 중등도 부상    | 전치 4~6주       | 노랑 |
| 35~59% | 중상           | 전치 8~12주      | 주황 |
| 60~89% | 심각한 중상    | 전치 12주 이상   | 빨강 |
| 90~    | 생명 위험      | 사망 가능성 높음 | 빨강 |

**주행 전 설정**

- 몸무게(kg), 자전거 종류(로드 9kg / MTB 13kg / 전기자전거 22kg / 공유자전거 18kg), 헬멧 착용, 백미러 카메라(전면/후면), "주행 시작" 버튼.

## 이유

- 백미러로 쓰려면 화면 가운데가 비어 있어야 한다.
- 막대 색이 경각심 게이지 역할을 겸해 화면 요소를 줄인다.
- 색만으로 구분하지 않도록 단계 글자를 같이 쓴다. 파랑·노랑·주황·빨강은 밝기도 서로 다르다.

## 영향

- 전치 주수는 공개 기준이 없어 위 표가 앱 자체 기준이다. 화면에 참고용임을 표시한다.
- 시안의 수치는 임시 공식이다. 실제 계산식은 계산 모듈 이슈에서 정한다.
- 카메라 장착 방향(전면/후면)에 따라 실제로 뒤가 보이는지는 실기기에서 확인해야 한다.
