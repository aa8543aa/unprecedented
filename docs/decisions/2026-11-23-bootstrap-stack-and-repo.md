## 배경

주제 "전례없는"의 아이디어가 확정되기 전에, 어떤 아이디어에도 쓸 수 있는 기반을 먼저 마련해야 했다.

## 검토한 선택지

1. **React + Vite + TypeScript**: 가볍고 빠른 SPA, 설정이 단순하다. 백엔드는 필요할 때 따로 붙여야 한다.
2. **Next.js + TypeScript**: 프론트와 API를 한 저장소에 둘 수 있다. 아이디어가 정해지지 않은 단계에서는 과하다.
3. **Tauri + React**: 데스크톱 앱 형태. Rust 툴체인이 필요해 진입 비용이 크다.

## 결정

- React + Vite + TypeScript로 시작한다.
- GitHub public 저장소 `unprecedented`로 만들고, 작업 관리는 GitHub Project를 쓴다.
- 로컬에서는 기존 작업물과 섞이지 않도록 별도 하위 폴더에 둔다.

## 이유

아이디어가 미정이므로 가장 범용적이고 가벼운 스택이 유리하다. 웹앱이면 바로 배포할 수 있고, 필요하면 나중에 데스크톱(Tauri 등)으로 감쌀 수 있다.

## 영향

- 서버 기능이 필요해지면 백엔드 구성을 별도 결정 문서로 남긴다.
- 저장소 이름은 아이디어 확정 후 바꿀 수 있다 (#4).
